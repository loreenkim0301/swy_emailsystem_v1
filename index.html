📧 EmailJS 학습 도구

이메일을 발송하는 외부 API를 연결하는 절차를 배워보아요. 아래 내용만 성공하면, 그 다음에는 내 웹사이트에 붙이는 것은 더 쉬워집니다.

1

EmailJS 설정

EmailJS 계정 정보를 입력하여 서비스를 초기화합니다. 초기화 후 템플릿에 설정된 기본 수신자에게 자동 테스트 이메일을 발송합니다.

EmailJS Dashboard → Account → General에서 확인
EmailJS Dashboard → Email Services에서 확인
EmailJS Dashboard → Email Templates에서 확인
2

연결 테스트

입력한 설정으로 EmailJS 연결 상태를 확인하고 실제 테스트 이메일을 발송해봅니다.

연결 테스트 결과를 받을 이메일 주소를 입력하세요
3

이메일 발송

실제 이메일을 작성하고 발송해봅니다. 모든 필드는 선택사항이며, 비워두면 EmailJS 템플릿에 설정된 기본값이 사용됩니다.

템플릿 변수: {{from_name}}
템플릿 변수: {{from_email}}
템플릿 변수: {{to_email}}
템플릿 변수: {{subject}}
템플릿 변수: {{message}}
